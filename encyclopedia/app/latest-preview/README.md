# 最新五星预览小样（国服 CN / 日服 JP）

> 用途：先确认版式与信息结构，确认后再批量采集官方公告数据与宣传图，最后并入主站。
> 打开方式：浏览器直接打开 `index.html`（纯静态、无外部依赖）。

## 1. 口径（按确认需求）

- 不再按角色分组；分 **国服 CN** 与 **日服 JP** 两种预览模式，顶部切换。
- 展示：**当期进行中全部 ★5** ＋ **近 30 天追加 ★5**；组内按 `dateISO` 最新倒序。
- 只保留卡面、角色、卡名、来源（卡池/活动）、日期、四色类型（未核留空）；**不写 Da/Vo/Pf 三围**。
- **官方公告宣传图（卡池 banner、活动横版 CG）下载到本地** `preview_img/banner/` 引用，不放外链临时图。

## 2. 文件结构

```
latest-preview/

├─ data.js              # 数据：PREVIEW_CARDS / PREVIEW_BANNERS / PREVIEW_META
├─ README.md            # 本说明

└─ preview_img/
   ├─ cards/            # ★5 卡面（下载核验后放入；当前为空，页面用占位）
   └─ banner/           # 官方公告宣传图（下载核验后放入；当前为空，页面用占位条）
```

## 3. 数据字段（PREVIEW_CARDS 每条）

| 字段 | 说明 |
|---|---|
| `id` | 稳定主键，建议 `cn-s5-序号` / `jp-s5-wikiId` |
| `mode` | `cn` 或 `jp` |
| `group` | `current`=当期进行中；`recent30d`=近30天；`archive`=往期或已纠错废弃锚点（页面/横幅均不渲染，仅留档）。正式版可用 `dateISO` 与系统日期自动滚动判定 |
| `star` | 固定 `5` |
| `char` | 角色名（国服中文名优先；无官方译法标注待核） |
| `card` | 卡名（日服保留日文原名；国服用官方中文） |
| `sourceType` | `scout`=卡池 / `event`=活动 |
| `sourceName` | 卡池或活动全名 |
| `dateISO` | `YYYY-MM-DD`，用于排序与近30天判定；来源不明不臆造 |
| `type` | 四色 `Sparkle/Brilliant/Flash/Glitter`；未核留 `""` |
| `img` | 本地卡面相对路径；`imgReady=false` 时页面不插图（占位、不裂图、不挂错人） |
| `imgReady` | `false` 占位；图下载就位后置 `true` |
| `sourceUrl` | 官方公告/卡面来源链接；缺失留空，禁止填失效猜测地址 |
| `note` | 口径备注、待补说明、是否含 MV 衣装等 |

宣传图 `PREVIEW_BANNERS`：`id/mode/title/dateISO/kind(scout|event)/img/imgReady/sourceUrl/note`。

## 4. 补图与补数据流程（批量阶段）

1. 采集来源优先级：官方公告（国服官网/官微/小红书官方号；日服官方账号）＞ 可溯源粉丝 wiki ＞ 其他；非官方渠道须本人、朝向、组合正确，不拿低清标准图顶替真图。
2. 卡面下载到 `preview_img/cards/`，横幅/横版 CG 下载到 `preview_img/banner/`；同名文件与 `img` 路径一致，再把 `imgReady` 置 `true`。
3. 每条补齐 `dateISO` 与 `sourceUrl`；`group` 在正式版改为按日期自动判定。
4. 核验：模式切换计数正确；占位条目 `imgReady=false` 不产生图片请求；不出现跨服混用（国服卡不得用日服图、反之亦然）；不挂错角色/朝向。
5. 质量红线：缺本人/朝向证据的图继续占位；多人同框默认不进单人 ★5 网格；横版 CG 只放横幅区。

## 5. 并入主站预留

- 数据数组名固定 `PREVIEW_CARDS` / `PREVIEW_BANNERS`，纯原生 JS、无框架依赖，可整体迁入 `root_index.html`。
- 建议以独立视图承载（新增“最新卡面”标签或替换现有 `enc`/`jp` 视图中的卡片区），保留现有时间线、排期、服装模块不动。
- 图片部署时 `preview_img/cards` → `assets/preview/cards`，`preview_img/banner` → `assets/preview/banner`，数据内相对前缀同步替换。
